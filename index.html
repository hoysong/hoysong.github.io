ft_irc

"C++98과 Linux epoll로 다중 클라이언트를 처리하는 IRC 서버"

  • RFC 1459/2812의 일부 명령을 구현해 사용자 등록, 채널 관리, 개인·채널 메시지와 운영자 기능을 지원합니다.
  • fork 없이 단일 epoll 이벤트 루프로 IPv4 TCP 연결과 여러 클라이언트의 입출력을 처리합니다.
  • 클라이언트별 수신 버퍼에서 CRLF 단위 메시지를 추출해 분할 수신과 연속 수신을 처리했습니다.
  • 명령 디스패치와 클라이언트·채널·소켓 책임을 분리하고, irssi와 netcat으로 동작을 검증했습니다.

IRC GUI Client — Qt Widgets

"Qt Widgets와 QTcpSocket으로 구현한 비동기 IRC GUI 클라이언트"

  • Qt Designer로 서버 접속 정보, 연결 상태, 송신 메시지와 수신 메시지를 구분해 확인하는 화면을 구성했습니다.
  • QTcpSocket의 connected, readyRead, errorOccurred 이벤트를 Signal/Slot으로 연결해 비동기 TCP 통신을 처리했습니다.
  • 연결 성공 시 PASS, NICK, USER를 자동 전송하고, 입력한 IRC 명령에 CRLF를 붙여 원시 요청·응답을 확인할 수 있게 했습니다.
  • UI를 담당하는 MainWindow와 네트워크 통신을 담당하는 IRCGuiControlClient로 책임을 분리했습니다.

MT Game of Life

"Game of Life 렌더링 파이프라인을 멀티스레딩하고 처리 시간을 비교한 개인 프로젝트"

  • C와 MiniLibX로 Conway's Game of Life 규칙, 랜덤·파일 기반 초기 맵과 실시간 셀 편집을 구현했습니다.
  • 화면을 8개 행 구간으로 나누고 배경, 격자, 셀 렌더링 단계를 pthread 작업으로 병렬화했습니다.
  • 각 렌더링 단계 사이에 pthread_join을 적용해 단계별 작업 순서를 보장했습니다.
  • 120프레임 처리 시간이 1,528ms에서 684ms로 줄어, 기준 구현 대비 처리 시간 55.2% 감소를 기록했습니다.
