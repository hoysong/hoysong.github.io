ft_irc

"C++98과 Linux epoll로 다중 클라이언트를 처리하는 IRC 서버"

  • RFC 1459/2812의 일부 명령을 구현해 사용자 등록, 채널 관리, 개인·채널 메시지와 운영자 기능을 지원하고, 과제의 기준 클라이언트인 irssi와 호환되도록 검증했습니다.
  • fork 없이 단일 epoll 이벤트 루프로 IPv4 TCP 연결과 여러 클라이언트의 입출력을 처리합니다.
  • 클라이언트별 수신 버퍼에서 CRLF 단위 메시지를 추출해 분할 수신과 연속 수신을 처리했습니다.
  • 명령 디스패치와 클라이언트·채널·소켓 클래스로 책임을 분리했습니다.
  • inspIRCd와 irssi를 이용해 서버·클라이언트 동작과 응답을 비교하며 호환성을 검증했습니다.
  • netcat으로 원시 IRC 명령을 테스트하고, tcpflow로 서버·클라이언트 사이의 TCP 스트림을 확인했습니다.

  • 2인 팀에서 파서를 주로 담당하고 실행부 일부도 구현했습니다.

MT Game of Life

"Game of Life 렌더링 파이프라인을 멀티스레딩하고 처리 시간을 비교한 개인 프로젝트"

  • Philosophers에서 익힌 멀티스레딩과 FdF·Cub3D에서 익힌 그래픽 구현 경험을 결합한 개인 프로젝트입니다.
  • C와 MiniLibX로 Conway's Game of Life 규칙, 랜덤·파일 기반 초기 맵과 실시간 셀 편집을 구현했습니다.
  • 화면을 8개 행 구간으로 나누고 배경, 격자, 셀 렌더링 단계를 pthread 작업으로 병렬화했습니다.
  • 각 스레드가 겹치지 않는 이미지 청크를 담당하게 해 렌더링 구간의 뮤텍스 없이 작업하고, 단계 사이에는 pthread_join()으로 실행 순서를 보장했습니다.
  • 274×142 맵을 1918×994 화면에 120프레임 렌더링하는 조건에서 처리 시간을 1,528ms에서 684ms로 줄여 55.24% 감소시켰습니다.
